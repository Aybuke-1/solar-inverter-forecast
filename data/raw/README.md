# Ham veri nasıl indirilir?

1. [Kaggle veri seti sayfasını](https://www.kaggle.com/datasets/anikannal/solar-power-generation-data) aç ve **Download** düğmesiyle ZIP dosyasını indir.
2. ZIP dosyasını aç.
3. Aşağıdaki iki dosyayı bu klasöre kopyala:
   - `Plant_1_Generation_Data.csv`
   - `Plant_1_Weather_Sensor_Data.csv`

Bu iki CSV dosyası GitHub'a yüklenmez. Projeyi yeniden çalıştırmak isteyenler aynı kaynaktan indirir.
